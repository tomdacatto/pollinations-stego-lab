Can a model find what another model hid?

A hider model draws a picture as SVG code with a secret hidden in it and no agreed scheme. A fresh seeker model is shown only the rendered picture, never the code, and is asked whether anything is hidden. Run it on any Pollinations models and see, per pair, how often the secret comes back and how often a seeker finds a message in a picture that has none. This is the setup of How does Fable 5.1 hide messages in images?
